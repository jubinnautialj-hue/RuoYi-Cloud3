============================================
二、需要您执行的操作
============================================

请按以下顺序执行操作：

--------------------------------------------
第1步：执行数据库脚本
--------------------------------------------

脚本位置：项目根目录下的 sql/ 文件夹

需要在【业务数据库（ry-cloud）】中按顺序执行以下脚本：

1. 01_flowable相关表.sql
   - 功能：创建流程分类、流程抄送、流程表单等业务表
   - 注意：执行前请确认数据库中不存在相同表名
   
2. 02_工作流中心菜单.sql
   - 功能：插入工作流相关的菜单数据
   - 注意：menu_id 从 2350 开始，如果冲突请修改
   
3. 03_数据字典.sql
   - 功能：插入流程状态字典数据
   - 注意：会先删除已存在的同名字典

执行方式：
- 使用 Navicat、DBeaver 或其他数据库工具
- 连接到 ry-cloud 数据库
- 按顺序打开并执行上述 SQL 文件
- 确认执行无错误

--------------------------------------------
第2步：配置 Nacos
--------------------------------------------

参考文件：sql/04_nacos配置参考.txt

需要在 Nacos 配置中心进行以下配置：

2.1 确认网关配置（已配置请跳过）
   - 检查 ruoyi-gateway-dev.yml 配置文件
   - 确认已添加 flowable 路由配置
   - 确认已添加 XSS 排除配置

2.2 新增 flowable 模块配置
   - 登录 Nacos 控制台（http://localhost:8848/nacos）
   - 点击【配置管理】->【配置列表】->【+】
   - 填写配置信息：
     * Data ID: ruoyi-flowable-dev.yml
     * Group: DEFAULT_GROUP
     * 配置格式: YAML
     * 配置内容: 复制 04_nacos配置参考.txt 中的完整配置
   - 【重要】修改数据库连接信息（用户名、密码等）
   - 点击【发布】保存

--------------------------------------------
第3步：启动后端服务
--------------------------------------------

启动顺序（必须按此顺序）：
1. ✅ Nacos（必须先启动）
2. ✅ Redis（必须先启动）
3. ✅ MySQL（必须先启动）
4. ✅ ruoyi-gateway（网关服务）
5. ✅ ruoyi-auth（认证服务）
6. ✅ ruoyi-system（系统服务）
7. ✅ ruoyi-flowable（工作流服务，新增）

ruoyi-flowable 服务端口：9308

启动验证：
- 查看控制台日志，确认无错误
- 确认服务已注册到 Nacos
- 确认数据库连接正常
- 确认 Flowable 自动创建了所需的表（ACT_ 开头的表）

--------------------------------------------
第4步：启动前端服务
--------------------------------------------

在 RuoYi-Cloud-Vue3 目录下执行：

方式一（npm）：
cd RuoYi-Cloud-Vue3
npm run dev

方式二（yarn）：
cd RuoYi-Cloud-Vue3
yarn dev

访问地址：http://localhost

--------------------------------------------
第5步：验证功能
--------------------------------------------

5.1 登录系统
- 打开浏览器访问 http://localhost
- 使用 admin 用户登录（默认密码：admin123）

5.2 验证菜单
- 确认左侧菜单显示：
  * 流程管理（包含：流程分类、表单配置、流程模型、部署管理）
  * 办公管理（包含：新建流程、我的流程、待办任务、待签任务、已办任务、抄送我的）

5.3 验证功能
- 点击【流程分类】，确认页面正常显示
- 点击【表单配置】，确认页面正常显示
- 点击【流程模型】，尝试新增一个流程模型
- 确认各页面无 JavaScript 错误

============================================
四、常见问题排查
============================================

问题1：执行 SQL 报错
- 检查数据库连接是否正确
- 确认使用的是业务数据库（ry-cloud）
- 检查表名或 menu_id 是否冲突

问题2：前端页面空白或报错
- 检查浏览器控制台（F12）的错误信息
- 确认所有依赖已正确安装
- 尝试清除浏览器缓存（Ctrl+Shift+Delete）
- 确认前端配置文件修改正确

问题3：后端服务启动失败
- 检查 Nacos 是否启动
- 检查 Nacos 配置是否正确
- 检查数据库连接是否正常
- 查看控制台详细错误日志

问题4：菜单不显示
- 确认已执行 02_工作流中心菜单.sql
- 确认 admin 用户拥有相关菜单权限
- 尝试退出后重新登录
- 检查 sys_user_role 和 sys_role_menu 表数据

问题5：流程图中文乱码
- 确认 Nacos 配置中已设置字体：
  flowable:
    activity-font-name: 宋体
    label-font-name: 宋体
    annotation-font-name: 宋体
- 如果系统中没有宋体，可以改为其他中文字体

问题6：保存流程模型时报错
- 确认网关配置中已添加 XSS 排除：
  xss:
    excludeUrls:
      - /flowable/model/save
- 检查请求是否被网关拦截

============================================
五、回滚方案（如果需要）
============================================

如果集成后需要回滚，请执行以下操作：

1. 数据库回滚：
   -- 删除工作流业务表
   DROP TABLE IF EXISTS wf_category;
   DROP TABLE IF EXISTS wf_copy;
   DROP TABLE IF EXISTS wf_deploy_form;
   DROP TABLE IF EXISTS wf_form;
   
   -- 删除工作流菜单（按 menu_id 范围删除）
   DELETE FROM sys_menu WHERE menu_id >= 2350 AND menu_id <= 2396;
   
   -- 删除数据字典
   DELETE FROM sys_dict_data WHERE dict_type = 'wf_process_status';
   DELETE FROM sys_dict_type WHERE dict_type = 'wf_process_status';

2. 后端回滚：
   - 从 ruoyi-modules/pom.xml 中移除 <module>ruoyi-flowable</module>
   - 停止 ruoyi-flowable 服务

3. 前端回滚：
   - 从 main.js 中移除 VForm3 相关代码
   - 从 router/index.js 中移除 workflow 相关路由
   - 删除 src/views/workflow/ 目录
   - 删除 src/api/workflow/ 目录
   - 删除 src/components/ProcessDesigner/ 目录
   - 删除 src/components/ProcessViewer/ 目录
   - 删除 src/modules/ 目录（如果只有 flowable 相关内容）
   - 删除 src/package/ 目录（如果只有 flowable 相关内容）
